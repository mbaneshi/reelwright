<h1 align="center">Reelwright</h1>

<p align="center"><strong>The open-source engine for a one-person film studio.</strong></p>

---

Reelwright runs a solo creator's whole production loop as code: finding a story, researching it, scripting, recording, editing and publishing, coordinated by an AI agent called **eve**.

The name joins *reel* (film) with *-wright*, a craftsman who builds, as in wheelwright or playwright.

## Status

**Not released yet.** Reelwright is being extracted from a private, working production system. Code lands here once it has been cleaned of personal data and made configurable for anyone to run. Watch or star the repo to follow along.
